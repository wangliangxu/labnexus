# LabNexus v0.4.0

LabNexus 是基于 Tauri v2、React 和 Rust 构建的远程 Jupyter 客户端与科学计算 AI 工作台。

## 本版功能

- 多标签页工作台：编辑 Notebook、代码、Markdown 和 JSON，预览数据表与图像。
- 连接远程 Jupyter Server / JupyterHub，支持 SSH 动态代理，并可检测和启动本地 Jupyter。
- 多会话终端，以及 Notebook 单元格执行、内核中断和重启。
- 科学计算 AI Agent：兼容远程模型 API 与本地模型，支持工具调用、思考模式配置和外部 MCP 扩展。
- 工具分级授权、会话与追踪记录，以及 macOS 钥匙串凭据存储。
- 中英文界面、浅色与深色主题，以及工作台交互改进。

## 安装包选择

| 系统 | 安装包 |
| --- | --- |
| macOS Apple Silicon（M 系列） | `aarch64.dmg` |
| macOS Intel | `x64.dmg` |
| Windows x64 | `.exe`（NSIS）或 `.msi` |
| Linux x64 | `.deb` 或 `.AppImage` |

当前安装包未配置开发者证书签名，macOS 安装包未公证，系统可能提示来源未验证。应用不包含 Python 或 Jupyter；使用本地 Jupyter 功能需另行安装对应环境。

前端生产构建和 Rust 单元测试已通过（33 项通过，1 项依赖本地 Jupyter 的测试跳过）。
