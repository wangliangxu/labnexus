# LabNexus v0.6.0

- 连接已运行的 Jupyter 时，可使用 `~/.ssh/config` 中的 Host 别名自动建立 SSH 隧道。
- 在连接面板选择「通过 SSH 启动」，填写主机别名和可选的远端 Python 路径。远端 Linux 或 macOS 的 Python 环境需已安装 Jupyter，留空时使用 `python3`。
- LabNexus 在远端回环地址上选择可用端口，启动后自动连接。停止连接时回收本次启动的进程。重连沿用保存的别名和 Python 路径。

前端构建和测试已通过。Rust 测试及本机回环 SSH 集成测试覆盖了真实 JupyterLab 的启动、文件访问、内核、终端和进程回收。
