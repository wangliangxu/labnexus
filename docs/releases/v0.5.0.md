# LabNexus v0.5.0

本版完善 AI 模型接口、ChatGPT 订阅登录与独立网络代理，保留现有 Jupyter 工作台与科学计算工具。

## 本版更新

- 默认模型调整为 `deepseek-flash`，默认接口改为 Responses API；统一模型、思考模式与推理深度设置，保留 Chat Completions 兼容选项。
- 完善 Responses 流式文本、推理摘要、并行函数调用与 Token 用量处理；保存并回传完整输出条目，支持多轮工具调用与加密推理上下文。失败、截断或缺失完成事件时不执行部分工具调用。
- 新增系统浏览器 ChatGPT 登录、多账号切换、授权模型列表、重新授权、退出与用量入口。订阅额度不足时提示用户，不自动切换至 API Key 计费。
- 新增 AI 独立代理页：API Key 与 ChatGPT 各自支持系统代理、手动代理和直连；支持 HTTP、HTTPS、SOCKS5 与 SOCKS5H，并提供不携带模型凭据的连通性测试。本地回环模型请求绕过应用代理。
- 登录令牌仅由后端管理，支持授权校验、刷新与受限权限文件存储；代理设置保存后供后续请求使用。

## 使用说明

- 在 AI 设置中选择 API Key 或 ChatGPT 登录方式，配置模型并保存。使用 ChatGPT 需账号具有对应服务资格，模型与额度以账号授权结果为准。
- 需要代理时，先在“AI 网络代理”配置对应路由并保存，再进行登录或模型请求。浏览器登录仍使用浏览器或系统 VPN 网络；系统 TUN 路由也可能影响直连模式。
- AI 代理与 Jupyter / SSH 连接代理分别配置。

## 验证范围

前端生产构建和 AI 模块的 47 项 Rust 测试通过，涵盖 Responses 解析、OAuth 校验、凭据存储和本地 HTTP / SOCKS5H 代理。真实账号登录、订阅模型调用与外部 VPN 连通性需在用户环境验证。

安装包按平台选择：macOS 使用对应 Apple Silicon / Intel 的 `.dmg`，Windows x64 使用 `.exe` 或 `.msi`，Linux x64 使用 `.deb` 或 `.AppImage`。安装包未配置开发者证书签名，macOS 未公证；本地 Jupyter 功能仍需自行安装 Python 与 Jupyter。
